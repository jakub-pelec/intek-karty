# Idea: reveal presentation

**Status:** parked. Not the current brief (that is cross-board scoring).

**Problem this would solve:** even when math is doing something, the duel does not *feel* like a fight. Attractiveness right now is mostly presentation — not enough effects, animation, or “stuff happening.” Core rules can still be wrong underneath; this note is the UI/feel track only.

**Who it hits:** whoever watches a duel (the player on `/match`, possibly stream overlay later). Does not change who can queue.

## What was already decided (soft)

- The match stays **watch-the-reveal**. Presentation should sell flips and score ticks, not add buttons.
- Do not treat “make it pretty” as a substitute for boards interacting. If we only animate today’s isolated tickers, whale lineups still auto-win and the fight still is not a fight.
- Cross-board scoring will *create* more moments worth presenting (your total can jump or drop when *they* flip). Presentation work should follow that rules change, or it will animate the wrong story.

## What “enough stuff happening” might mean (not committed)

- Each flip has a readable beat: whose card, which tags, which scores changed.
- Totals that go **down** are as visible as totals that go up (or the new rules will look like a bug).
- Enemy influence is named on the board (“their Snack paid your Cat”), not only in a tally list.
- Practice / admin rewind still has to stay understandable if animations replay.

## Explicit non-goals until rediscovered

- A stream-native spectator skin (unless that becomes the brief).
- New game modes or live both-players-present timing.
- Particle noise with no rules meaning.

## Open questions

- Is the first presentation pass **the existing match board** only, or also deck-builder “points” which will lie once scoring needs an opponent?
- How much motion is required on a phone vs desktop?
- Does admin god view show the same theater or a dry ledger?
